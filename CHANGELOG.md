# Changelog

## 0.3.0

- **smell_scan.py fixes**, found by mutation-checking our own scanner (its tests scored 43%, now 87%): `typeof`-only JS assertions were never flagged (a stray backspace had replaced `\b` in a regex); `@patch` decorators were counted twice, so `mock-heavy` fired at two; `assert m.called` slipped through both mock-only and weak-assert; a bare `assert f()` is now weak like `assertTrue(f())`; a snapshot-only test is no longer reported as having no assertion. New exact-expectation tests for every rule, and a repo-wide guard against control characters in source.
- **Self-check of `mutation_check.py`** with the whole suite as the test command: 55% on a 60-mutant sample, 26 of 27 survivors now killed by `tests/test_selfcheck_gaps.py` (lexer edge cases, merge-base `--base`, exit codes, `pid_alive`, workdir copy, report output); one provably equivalent survivor recorded in `.mutation-ignore`. The two fallback syntax checks (project TypeScript without the language service, Node's type stripper) are tested too, and the equivalence-report test no longer depends on the Python version. The suite now runs in a private temp directory, so a mutated copy of the tool can no longer delete the backups of the run that is testing it.
- **Second, larger self-check**: a uniform random sample of 240 of the tool's 1,762 mutants, each judged by the whole suite (measured on Windows, Python 3.12). Before: **68%** (164 killed, 76 survived). New tests in `tests/test_selfcheck_gaps2.py` kill 61 of the 76; 13 are provably equivalent and recorded in `.mutation-ignore`, each with its reason; 2 are left as survivors and not hidden. On the same sample that is 225 of 227, but that number is flattering by construction, because the tests were written for exactly those mutants. So the suite was measured again on **120 fresh mutants** the first sample had not drawn: **76%** (91 killed, 29 survived), which is the honest score after the first batch of tests. Of those 29, 22 are now killed too, 2 more are recorded as equivalent and 5 are left. In total 360 of the 1,762 mutants (20%) were sampled; the suite has not been measured on a third, independent sample, so its score after the second batch is known only to be at least that 76%. The 7 survivors left on purpose: two tuning numbers (the 5-second grace period after a timeout kill; the x5 time allowance for the sanity run in a copy); three that are equivalent but share their source text with a mutant that is not, so an ignore entry would hide a real bug; a backup manifest without a pid, which the tool never writes; and the explicit removal of the links in a worker copy before the copy is deleted, which looks redundant on Python 3.9+ but was not proven so on every platform. `tests/test_selfcheck_gaps2.py` has 76 tests. What they cover: the JS lexer at the end of a file and around regexes, templates, block comments, `?.` and `.5`; statement boundaries (`case` labels, continuation lines, `for` headers, tagged templates); emoji offsets in TypeScript ranges; `count_tests`; `detect_cmd` with `package.json`; `--restore` (what is counted, timestamps); `--seed` and sampling; `--timeout` on the baseline; `--jobs 0`; an interrupt killing the running test processes; a mutant (bytes and timestamp) being undone before the next file is mutated; crash recovery when a timestamp is slightly off or a backup cannot be read; the default of `--show`; the tail of a failing baseline; JavaScript without Node installed; and the report lines.

## 0.2.0

- **JS/TS mutator rewritten** as a tokenizer with bracket and statement structure (was line-based): multi-line conditions, `a<b` without spaces, `${...}` expressions, arrow bodies, brace-less `if (x) save();`, ASI-aware `return`, TypeScript generics and type-only statements. Mutants of the demo source and a deliberately tricky file are all checked with `node --check`.
- **Type-aware TypeScript**: with the project's `typescript`, a persistent language service type-checks each mutant (the file and the files importing it) and drops the ones that no longer compile; only errors the mutant adds count (`--no-typecheck` to skip). Without TypeScript, Node's built-in type stripper (22.13+) is used for an exact parse.
- **Real TypeScript parser when available**: if the project has `typescript` installed, it identifies types, declarations, imports and JSX markup exactly (nothing is installed or downloaded by this tool), and every TS mutant is syntax-checked with it. Tested against the real compiler in CI.
- **`--jobs N`**: test mutants in parallel copies of the project; the project itself is never touched. Each copy is verified (suite passes; suite fails when sources are broken) and the run falls back to sequential when it cannot be trusted.
- **Equivalent mutants**: provably identical Python mutants are skipped automatically; `.mutation-ignore` accepts reasoned survivors (reason required, stale entries reported); `# pragma: no mutate`.
- **Crash recovery**: originals are backed up; Ctrl+C, SIGTERM, Ctrl+Break and, on Windows, console close / logoff / shutdown restore immediately; after SIGKILL the next run self-heals untouched mutants (a file you edited since is never overwritten); `--restore` forces it.
- `--show`, `--print-ignore`, `--color`, `--restore`; recorded demo; CI matrix on Ubuntu, Windows and macOS.
